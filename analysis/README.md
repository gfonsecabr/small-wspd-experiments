# Analysis

Each script reads the experiment outputs from `data/` (or from the folder in the environment variable `DATA`) and
writes to `results/` (or `RESULTS`). Run them from the repository root:

```
python3 analysis/make_tables_figs.py      # Fig. summary, ratio, time, lb; Table exp; results/tables/summary.txt
python3 analysis/ls_compare.py            # Fig. ls, Fig. lstotal; Table lstime; results/ls_cmp_summary.md
python3 analysis/partition_conv.py        # Fig. partconv; Table partconv; results/partition_summary.txt
python3 analysis/text_numbers.py          # every number quoted in the text: results/text_numbers.txt
python3 analysis/lns_params.py           # the tests of the LNS parameters: results/lns_params_summary.md
python3 analysis/inputs_fig.py           # Fig. inputs (runs src/exp, needs the CG:SHOP instances)
DATA=runs python3 analysis/make_tables_figs.py   # the same for your own runs (experiments/run.py)
```

| Script | Outputs | Paper |
| --- | --- | --- |
| `make_tables_figs.py` | `figs/summary.pdf`, `figs/ratio.pdf`, `figs/time.pdf`, `figs/lb.pdf`, `figs/per_point.pdf`, `tables/results.tex`, `tables/summary.txt` | Fig. summary, Fig. ratio, Fig. time, Fig. lb, Fig. perpoint, Table exp |
| `ls_compare.py` | `figs/ls_convergence.pdf`, `figs/ls_total_time_inputs.pdf`, `tables/ls_time.tex`, `ls_cmp_summary.md` | Fig. ls, Fig. lstotal, Table lstime |
| `partition_conv.py` | `figs/partition_conv.pdf`, `tables/partition.tex`, `partition_summary.txt`, `partition_wide.csv` | Fig. partconv, Table partconv |
| `text_numbers.py` | `text_numbers.txt` | the numbers of the abstract, the introduction, and Section Experiments, and the lower end 1.503 of the open problem (from `sweep_unpruned.csv`) |
| `lns_params.py` | `lns_params_summary.md` | the tests of the LNS parameters (appendix, paragraph "Local search": the ranges tested, and that the CPLEX limit and the number of candidates per pair change the sizes by at most 0.3%) |
| `inputs_fig.py` | `figs/inputs.pdf` | Fig. inputs (one instance per input family with n = 1000, generated by `src/exp`) |
| `catchup.py` | `DATA/catchup.csv` | input of `text_numbers.py`: the time until reshape from CK exact is smaller than the sweep's output, and how far reshape from the sweep is ever ahead of reshape from CK exact at equal total time. It needs the traces of all reshape runs and `ls_setup.csv`, so it runs on a full rerun (`DATA=runs`), not on `data/`, which ships its result |
| `reference.py` | (module) | paths and the reference value of an instance |
| `figutil.py` | (module) | legend order of the figures |

`partition_conv.py` also checks that the partition runs reproduce the paper's runs: the sizes of the sweep, CK exact,
the optima, and sweep + reshape and CK exact + reshape (rerun with the logged number of rounds) must be identical to those in `exp*.csv` and
`ls_all_*.csv`, and every quadtree output must be a verified partition.

## Reference value

Every size is divided by the reference of its instance: OPT where it is proven optimal (by CPLEX in `exp2_opt.csv`, or by `optx` in `optx.csv`), and otherwise the lower bound LB of the paper, computed by `src/lb_swap` and checked by `src/check_lb` (column `lb` of
`lb_check.csv`; the number of steps of the sweep is the column `steps`). Since LB ≤ OPT, a ratio to LB overestimates the ratio to OPT. CPLEX solutions that are
not proven optimal are never used. A group of instances whose references are all LB is marked † in the tables and
with open markers in the figures, and a group that mixes both kinds of reference with ‡ and half-filled markers.
